# BooklyPro

BooklyPro is a Django-based SaaS platform for online booking management for small businesses.

## Tech Stack

- Python
- Django
- PostgreSQL
- Redis
- Celery
- Azure App Service
- Azure Database for PostgreSQL
- GitHub Actions
